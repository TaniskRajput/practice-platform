Problem Statement: Check if Matrix Is Valid

An n x n matrix is valid if every row and every column contains all the integers from 1 to n (inclusive).

Given an n x n integer matrix matrix, return true if the matrix is valid. Otherwise, return false.

Constraints:

	
n == matrix.length == matrix[i].length
	
1 <= n <= 100
	
1 <= matrix[i][j] <= n

Example Test Cases:

Test Case 1

Input: matrix = [[1,2,3],[3,1,2],[2,3,1]]

Output: true

Explanation: In this case, n = 3. Every row and column contains the numbers 1, 2, and 3. Hence, return true.

Test Case 2

Input: matrix = [[1,1,1],[1,2,3],[1,2,3]]

Output: false

Explanation: In this case, n = 3. The first row [1,1,1] does not contain integers 2 and 3. Hence, return false.

Test Case 3

Input: matrix = [[2,2,2],[2,2,2],[2,2,2]]

Output: false

Explanation: Duplicate values exist in every row and column, missing integers 1 and 3.

2. SQL Database Reference Solution

SELECT 
 c.customer_name,
 COUNT(DISTINCT o.order_id) AS total_orders,
 SUM(oi.quantity * oi.unit_price) AS total_spent
FROM Customers c
JOIN Countries cnt ON c.country_id = cnt.country_id
JOIN Orders o ON c.customer_id = o.customer_id
JOIN Order_Status os ON o.status_id = os.status_id
JOIN Order_Items oi ON o.order_id = oi.order_id
WHERE cnt.country_name = 'USA'
 AND os.status_name = 'Completed'
 AND o.order_date BETWEEN '2025-01-01' AND '2025-12-31'
GROUP BY c.customer_id, c.customer_name
HAVING SUM(oi.quantity * oi.unit_price) > 1000
ORDER BY total_spent DESC;

3. Web Development Reference Solution

<script>
 let count = 0;
 const countEl = document.getElementById('count');
 const msgEl = document.getElementById('status-msg');

 document.getElementById('inc-btn').addEventListener('click', () => {
 if (count < 10) {
 count++;
 countEl.textContent = count;
 msgEl.textContent = count === 10 ? "Maximum limit reached!" : "";
 }
 });

 document.getElementById('dec-btn').addEventListener('click', () => {
 if (count > 0) {
 count--;
 countEl.textContent = count;
 msgEl.textContent = count === 0 ? "Minimum limit reached!" : "";
 }
 });
</script>
