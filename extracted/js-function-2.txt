1.

A developer creates a button:

 

<button id="btn1" onclick="updateAttr(this)">Click Me</button>

<script>

function updateAttr(el) 

{ el.setAttribute("data-status", "active"); 

document.write(el.getAttribute("data-status"));

} 

</script> 

What is the output when the button is clicked?

Options:

A. active

B. undefined

C. Error

D. Click Me

Answer: A

Explanation: setAttribute sets data-status, and getAttribute fetches it.

<script> 

function toggleAttr(btn) { if(btn.hasAttribute("disabled"))

{ btn.removeAttribute("disabled"); }

else { btn.setAttribute("disabled", "true"); }

document.write(btn.hasAttribute("disabled")); }

</script> 

What happens when the button is clicked once?

Options:

A. true

B. false

C. Error

D. undefined

Answer: A

Explanation: hasAttribute returns true after disabled is set.
