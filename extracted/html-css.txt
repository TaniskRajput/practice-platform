1.

A developer creates the following snippet to draw a live graph using JavaScript:

 

<canvas id="graphCanvas"> Browser does not support canvas </canvas> 

What is the purpose of this element?

Options:

A. To create a video player

B. To draw graphics dynamically using JavaScript

C. To embed 3D models directly

D. To display static images

Answer: B

2.

An audio streaming website adds this code:

 

<audio controls> <source src="song.mp3" type="audio/mpeg"> </audio> 

What will happen if the browser doesn’t support the <audio> tag?

Options:

A. It will show an error message

B. Nothing will appear

C. The text or fallback content inside <audio> will display

D. The browser will play the audio automatically

Answer: C

A. autoplay

B. loop

D. preload
