Problem Statement: Text Encryption Grid

An English text needs to be encrypted using a grid encryption scheme.

First, remove all spaces from the text. Let L be the length of this modified string. Then, arrange the characters in a grid with rows and columns satisfying:

floor(√L) ≤ rows ≤ columns ≤ ceil(√L)

Ensure that rows × columns ≥ L. If multiple grids satisfy this condition, select the one with the minimum area (i.e., rows × columns). Write the encoded message by reading column by column, separating each column with a space.

Constraints:

	
1 <= length(s) <= 81
	
s contains Latin characters and spaces.

Example Test Cases:

Test Case 1

Input: s = "if man was meant to stay on the ground god would have given us roots"

Output: "imtha tfaha odmyg erneu gtwru gmsos nneod eveag eerte"

Explanation: After removing spaces, length L = 54. √54 is between 7 and 8. So, grid is 7 rows and 8 columns (area = 56 ≥ 54). Reading columns produces 8 words separated by spaces.

Test Case 2

Input: s = "have a nice day"

Output: "hae and via ecy"

Explanation: Length L = 12 without spaces. √12 is between 3 and 4. Dimensions chosen are 3 rows and 4 columns. Grid:

have

anic

eday

Output column-wise: "hae and via ecy".

Test Case 3

Input: s = "feedthedog"

Output: "fto eeh ddg"

Explanation: L = 10. √10 is between 3 and 4. 3 × 3 = 9 < 10, so grid dimensions must be 3 × 4.

2. SQL Database Reference Solution

SELECT 
 p.plan_name,
 COUNT(DISTINCT s.subscription_id) AS total_subscriptions,
 COUNT(DISTINCT CASE WHEN ps.status_code = 'SUCCESS' THEN r.renewal_id END) AS successful_renewals,
 ROUND(
 (COUNT(DISTINCT CASE WHEN ps.status_code = 'SUCCESS' THEN r.renewal_id END) * 100.0) / 
 COUNT(DISTINCT s.subscription_id), 2
 ) AS renewal_rate
FROM Plans p
JOIN Subscriptions s ON p.plan_id = s.plan_id
LEFT JOIN Renewals r ON s.subscription_id = r.subscription_id
LEFT JOIN Payment_Status ps ON r.status_id = ps.status_id
WHERE s.start_date BETWEEN '2026-01-01' AND '2026-03-31'
GROUP BY p.plan_id, p.plan_name
HAVING COUNT(DISTINCT s.subscription_id) > 50
ORDER BY renewal_rate DESC;

<script>
 const passInput = document.getElementById('pass');
 const confirmInput = document.getElementById('confirm-pass');
 const msg = document.getElementById('feedback-msg');

 function validate() {
 const val1 = passInput.value;
 const val2 = confirmInput.value;

 msg.textContent = "Passwords Match";
 msg.style.color = "green";
 } else {
 msg.textContent = "Passwords do not match or too short";
 msg.style.color = "red";
 }
 }

 passInput.addEventListener('input', validate);
 confirmInput.addEventListener('input', validate);
